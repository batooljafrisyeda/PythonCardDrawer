# 🎴 Python Card Drawer

A desktop application built with Python that randomly draws and displays playing cards with a shuffle sound effect.

## Features
Displays playing cards using a graphical interface
Animates the card selection before showing the final card
Plays a shuffle sound effect
Prevents the same rank from being drawn consecutively

Built with Python, Tkinter (GUI), Pillow (image loading and resizing), Pygame (sound effects)

## How to Run
- Make sure Python is installed on your computer
- Download or clone this repository and open the project folder in VS Code (or your preferred code editor).
- Open a terminal in the project folder and install the required libraries: pip install pillow pygame-ce
- In the same terminal, run the application: python main.py

Make sure the Cards/ and Sounds/ folders are present in the project directory.
